## Scope
Landing `/` (Persuade) and application `/app` (Operate), one shared dark world. Direction pinned by the user's brief ("centre de contrôle sombre premium"); no concept roll. Build path: code-led (no image generation).

## Audience and job
Jury/recruiter and rebalancing operator, equal priority; shown on laptop/projector and online, mobile included. Landing: understand the project in 30 s and enter the app. App: spot critical stations, act on transfers.

## Direction contract

THESIS: The network itself is the interface. The landing opens on the real stations drawn where they are, alive with the feed; the pipeline is a transit line with packets in motion. Refuses the hero-metric template, card grids and neon-on-black.
OWN-WORLD: Dark ink ground (#070b14, panels #0c1322/#101a2e, hairlines #1b2a47), light text tiers, state colours validated for dark (vide #e66767, saturée #9085e9, faible #c98500, élevée #3987e5, normale #199e70, hors service grey). Wayfinding/transit-diagram vocabulary: ring stations, 1.5px line work, signage-style Bricolage Grotesque headings, Geist UI, Geist Mono for figures. Primary action is a light button on the dark ground.
STORY: The visitor understands the problem (empty vs full stations), sees the network live with honest freshness, follows the data path from feed to screen, reads what is heuristic and not done, then enters the app.
FIRST VIEWPORT: Full-bleed canvas of the real stations at the right/behind; left: H1 "Où manquent les vélos, où manquent les places ?", one live sentence with counted numbers, primary "Accéder au projet" (light, 48px+) and a quiet secondary link; live status line bottom-left. Mobile: network above, text below.
FORM: Live network canvas plus transit-line pipeline (position 1: assigned by the brief, no seed); app: control shell with map, tabs, KPIs; signature move = transfers as trucks travelling along their segments, LIVE indicator pulsing on each stream message.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
